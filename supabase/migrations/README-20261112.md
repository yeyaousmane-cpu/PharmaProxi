# Migrations du 12 novembre 2026 — annuaire national et recensement de Faladié

Sept migrations ont été appliquées à la base de production ce jour. Les deux
premières figurent intégralement dans ce dossier. Les cinq suivantes ont été
appliquées directement et sont conservées dans l'historique de migrations de
Supabase (`supabase_migrations.schema_migrations`, colonnes `version`,
`name`, `statements`).

Pour les matérialiser en fichiers locaux :

```bash
supabase db pull            # écrit les migrations manquantes dans ce dossier
supabase migration list     # compare le local et le distant
```

## Règles suivies

- **Aucune donnée inventée.** Tout champ absent de la source reste `NULL`. Un
  numéro de téléphone qui ne tient pas sur huit chiffres n'est pas « corrigé » :
  il reste vide et le numéro publié est reporté dans `to_verify`.
- **Aucune suppression.** Les doublons sont renommés « (fiche doublon
  archivée) » et dépubliés, jamais supprimés. Chaque paire est enregistrée dans
  `facility_duplicate_candidates`.
- **Aucune structure présentée comme partenaire** sans accord.
- **Aucune position présentée comme exacte** si elle ne l'est pas : la colonne
  `position_precision` distingue `confirmee`, `a_confirmer`, `approximative`
  (coordonnée partagée avec d'autres fiches) et `inconnue`.
- **Statut d'attente conservé** pour les structures non confirmées :
  `is_published = false`, `reliability` à `incomplet` ou `a_confirmer`,
  `operating_status = 'non_confirme'`, et `to_verify` décrit ce qui reste à
  vérifier avant publication.
- **RLS intacte.** Les nouvelles tables sont créées avec `row level security`
  activée et les mêmes politiques que les tables voisines ; aucune politique
  existante n'a été désactivée ni assouplie.

## Retour arrière

```sql
-- rattachements automatiques à une commune
update public.facility_listings f set commune_id = b.old_commune_id
  from public.geo_commune_backfill b
 where b.target_table = 'facility_listings' and f.id = b.row_id;
delete from public.geo_commune_backfill;

-- import du classeur
delete from public.facility_offers
 where source like 'Repertoire national des structures sanitaires du Mali (2026)%';
delete from public.facility_listings
 where source like 'Repertoire national des structures sanitaires du Mali (2026)%';
delete from public.pharmacy_listings
 where source like 'Repertoire national des structures sanitaires du Mali (2026)%';

-- précision de position
alter table public.facility_listings drop column position_precision;
```

Les fiches archivées comme doublons se retrouvent par leur nom
(`name like '%(fiche doublon archivée)'`) et se réactivent en rétablissant le
nom d'origine et `is_published = true`.
